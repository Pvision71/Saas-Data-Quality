# Quickstart Guide

This guide walks through a simple scenario of using the platform to profile a legacy database.

## 1. Create a Project
- Log in to the platform.
- Navigate to the 'Projects' dashboard.
- Click 'New Project' and give it a name, e.g., "Legacy CRM Migration".

## 2. Add a Data Source
- Inside the project, go to the 'Data Sources' tab.
- Click 'Add Data Source'.
- Select 'Legacy Database' and enter the connection details for your source database.

## 3. Run Data Profiling
- Once the data source is connected, click the 'Profile' button.
- The platform will initiate a data profiling job.

## 4. View Results
- When the job is complete, navigate to the 'Profiles' tab.
- View the generated data profile, which will show details about the data quality, schema, and relationships in the source database.
